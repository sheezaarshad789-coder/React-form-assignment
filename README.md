# React-form-assignment

A modern React form assignment from the MN tech Academy, designed as a responsive, premium-style Maison signup experience. The form collects a user's name, email address, password, and password confirmation, along with their agreement to the terms and privacy policy.

## Form requirements

- Includes username, email, password, confirm password, and terms checkbox fields.
- Requires the name, a valid email address, and agreement to the terms.
- Shows an error when the password is shorter than 6 characters.
- Shows an error when the password and confirmation do not match.
- Keeps the submit button disabled until the terms checkbox is selected.
- Displays a success message after a valid submission and resets the form.
- Provides show/hide password controls and responsive styling for mobile screens.

## Getting started

Install the dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```
